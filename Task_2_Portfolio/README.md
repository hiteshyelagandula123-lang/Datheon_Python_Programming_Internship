# Stock Portfolio Performance Tracker

## Project Description
This project is a Python-based Stock Portfolio Performance Tracker developed as Task 2 of the Datheon Python Programming Internship. It allows users to enter stock ticker symbols, share quantities, and purchase prices, then calculates the total investment, current portfolio value, profit or loss, and percentage return.

## Features
- Stock ticker validation using a company dataset.
- Calculates invested amount and current portfolio value.
- Calculates profit/loss and percentage returns.
- Displays a portfolio summary in the terminal.
- Exports results to `portfolio_summary.csv`.

## Technologies Used
- Python 3
- CSV module
- File handling

## Files
- `portfolio.py` — Main Python application.
- `stocks.csv` — Company information dataset.
- `portfolio_summary.csv` — Generated portfolio report.

## How to Run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run:

   `python portfolio.py`

4. Enter the stock ticker, number of shares, and purchase price when prompted.
5. Type `DONE` to finish and generate the report.

## Price Data Note
The current version uses illustrative sample prices configured in the Python program. These are not live market prices and should not be used for actual investment decisions.
